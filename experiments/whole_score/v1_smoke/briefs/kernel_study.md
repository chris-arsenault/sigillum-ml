# Kernel study brief

Compose a four-bar chamber miniature for flute and cello in C major.

- Present a clear two-impulse theme over a bass in bars 1–2.
- Return to recognizably the same material in bars 3–4 with audible change.
- Keep both instrumental roles legible.
- Make the midpoint sound connected rather than restarted.
- Preserve some reserve; continuous activity is not required.

The starting score supplies the frozen form, identities, requirements, and
initial statement. Each evaluated system receives the same brief and starting
source. The brief does not prescribe the winning notes.
